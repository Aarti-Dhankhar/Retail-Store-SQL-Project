# Retail Store SQL Project

## Project Overview
This project focuses on analyzing a retail store database using SQL and MySQL.

## Objective
The objective of this project is to analyze customers, orders, products, sales, payments and other business data to generate useful insights.

## Tools Used
- MySQL
- SQL
- GitHub

## Database Tables
- Customers
- Orders
- Order Items
- Products
- Payments
- Stock
- Product Reviews

## SQL Concepts Used
- SELECT, WHERE
- GROUP BY, HAVING
- Aggregate Functions
- JOINs
- Subqueries
- CTEs
- Set Operations
- Window Functions
- Views
- Triggers
- Date Functions

## Analysis Covered
- Customer spending analysis
- Order analysis
- Product performance
- Category-wise sales
- Best-selling products
- Customer purchasing behaviour
- Payment analysis
- Sales analysis

## Key Skills Demonstrated
- Data filtering and aggregation
- Joining multiple tables
- Subquery-based analysis
- Ranking and analytical queries
- Business-oriented SQL analysis
